# ui-make

一个用于 Web、桌面软件和移动 App 的 Codex 技能。它把开发者的 UI 描述转成可反馈的组件样例，再沿用项目技术栈实现和验证。

## 安装

将 `skills/ui-make` 整个目录复制到 `~/.agents/skills/`（供所有项目使用），或放到项目的 `.agents/skills/`（仅供该项目使用）。安装后，技能入口应位于目标目录下的 `ui-make/SKILL.md`。若技能列表未刷新，重启 Codex。

## 使用

在 Codex 里明确调用，例如「`$ui-make`，把通知设置页做得更紧凑，让我一眼看到还有哪些通知可以开启。」也可以直接提 UI 改动，例如「把侧栏收窄一点」，由 Codex 按任务匹配技能。仅询问现有组件实现时，Codex 直接解释。

「你会怎么做」会先得到建议或草图。「可以试试看」会先得到小样，可运行的版本在隔离环境制作。预览期间可以继续试调，选定后说「把这版应用到项目」即可开始实现。也可以直接指定项目改动，例如「把项目侧栏缩到 224 px」。

尚未确定的关键设计会先给出精简组件代码，有条件时附上可运行预览。风格描述有多种解释时，用相同内容做两个小样，聚焦一个视觉差异。改版后在相同条件下对照易辨性、美观性和简洁性，并实测受影响的原有行为，例如保存后刷新是否保留设置。

如果某个方案会让界面明显更难读或更难用，技能会先说明具体影响和替代做法。了解取舍后，你仍可以确认按原效果实现。

技能也会在需要时调查指定风格、核实图片和纹理的商用许可，或调用环境中已具备的相关工程技能。 [查看完整技能](skills/ui-make/SKILL.md) · [Skills for Real Engineers](https://github.com/mattpocock/skills#reference)
